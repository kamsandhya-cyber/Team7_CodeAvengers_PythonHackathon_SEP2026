# Team 7 – Code Avengers
## Python Hackathon – September 2026
### Heart Failure Analysis

This repository contains the complete work completed by **Team 7 – Code Avengers** for the **September 2026 Python Hackathon**.

Our project focuses on transforming complex heart failure clinical data into meaningful insights using Python-based data analysis and visualization.

## Project Overview

The hackathon followed a complete analytics workflow:

1. **Understand** – Review the structure of the clinical datasets, patient keys, variables, and outcomes.
2. **Clean** – Standardize data, validate patient identifiers, handle missing values, and prepare reusable cleaned datasets.
3. **Analyze** – Perform descriptive, prescriptive, and predictive analysis.
4. **Consolidate** – Combine the strongest findings from all team members into a consistent final format.
5. **Visualize** – Present the key results through an interactive dashboard and final presentation.

## Dataset Summary

- **7 clinical datasets**
- **2,008 patients**
- **15,362 prescription records**
- **3 analytics layers:** Descriptive, Prescriptive, and Predictive

## Repository Structure

The files are numbered so that the project workflow is easy to follow:

- **Category 1 – Data Cleaning**  
  Contains the cleaned and validated datasets/notebooks for each clinical domain.

- **Category 2 – Descriptive Analysis**  
  Explores important patient patterns, heart-failure severity, biomarkers, and clinical relationships.

- **Category 3 – Prescriptive Analysis**  
  Focuses on translating observed patterns into monitoring priorities and actionable clinical insights.

- **Category 4 – Predictive Analysis**  
  Uses multiple clinical factors together to identify important higher-risk patient patterns.

- **Category 5 – Dashboard / Visualization**  
  Combines the major findings into one interactive dashboard for easier interpretation.

## How to Review the Project

Use the **file index** to understand what each file contains and follow the numbering to review the project in order.

When reviewing the analysis, compare the final questions, reasoning, visualizations, and conclusions with the project requirements and reference examples.

We also recommend peer review using the grading rubric, where applicable, to check the clarity, accuracy, and consistency of the analysis.

## Key Takeaway

The overall project moves from:

**Raw Clinical Data → Validated Analysis → Meaningful Insights → Actionable Intelligence**

The final dashboard brings together patient profiles, clinical patterns, risk signals, and outcomes into one decision-focused view.
